# GARAGE Flashcards NEW

Оригинальные страницы, тексты и дизайн GARAGE сохраняются. Каталог редактируется через [Pages CMS](https://app.pagescms.org/) в **Tirvia/GARAGE_Flashcards_NEW**.

## Проверка знаний и регулярное повторение

Открой [проверку знаний](https://tirvia.github.io/GARAGE_Flashcards_NEW/training.html) через существующую кнопку **«Проверить знания по всему меню»** на главной. Её текст и оформление не менялись. Старая тренировка карточками доступна в новом меню по ссылке **«Привычные карточки»**.

- **Проверка знаний:** 12 вопросов из автоматически сформированного банка: узнать блюдо или напиток по фото; выбрать входящие ингредиенты; найти лишний ингредиент; сравнить составы двух блюд; определить блюдо по сочетанию ингредиентов; ответить на вопрос Гостя. Можно выбрать раздел или «Всё меню». После ответа показывается пояснение.
- **5 минут на меню:** 8 коротких вопросов. Вначале повторяются сложные и подошедшие по сроку карточки, затем новые. После правильных ответов интервалы повторения увеличиваются: 1, 3, 7, 14 и 30 дней.
- **Повторить ошибки:** показывает только блюда, где ответ был неправильным; успешное повторение убирает их из списка.
- **Вспомнить состав:** самостоятельная тренировка по памяти. Система показывает состав, а сотрудник отмечает, вспомнил ли его. Это самооценка, а не объективная аттестация.
- **Что изменилось:** добавления, изменения названия, состава, фото и раздела блюда, снятие с публикации автоматически определяются при сборке каталога. Доступные обновлённые позиции можно отдельно проверить.
- **Результат:** количество правильных ответов, ошибки и подборка для повторения. История и интервалы сохраняются **только в localStorage на данном устройстве**, без аккаунта и без отправки результатов работодателю.

### Как включить вопросы по ингредиентам для новых блюд

После сверки текста с актуальной рецептурой включи в Pages CMS поле **«Состав проверен для тестов»**. **Вручную создавать вопросы и варианты ответов не нужно:** генератор сам комбинирует проверенные ингредиенты, находит отличия между карточками и подбирает варианты. По одному блюду может появляться несколько типов вопросов; при повторении по возможности выбирается другой шаблон. Вопросы об ингредиентах и рекомендации по просьбе Гостя создаются только на основе таких карточек. Сейчас помечены пять ранее сверенных составов драников. Остальные 186 карточек уже участвуют в проверке по фотографиям и названиям. Отметка о проверке состава не заменяет обязательного уточнения аллергенов и пищевых ограничений.

Вопросы «лишний ингредиент» и «сравнение блюд» используют только **подтверждённые рецептуры** и формулировку «указан в составе». Это тест на знание записанного меню, а не справка об аллергенах. Ответы сверяются по каталогу автоматически; после ответа показывается правильный вариант и краткое объяснение. Генератор работает по шаблонам без внешнего ИИ-сервиса.

### История изменений

Начиная с внедрения функции GitHub Actions автоматически сравнивает опубликованный каталог с предыдущей версией и обновляет `data/menu-change-history.json` и `js/menu-changes.js`. До первого изменения меню лента будет пустой. Для удаления или архивирования запись остаётся в истории, но удалённое блюдо больше не предлагается для тренировок.

## Работа с меню (без редактирования кода)

1. Откройте раздел **«Блюда и напитки»** в Pages CMS.
2. Выберите существующее блюдо или создайте новое. Укажите название, раздел, признаки состава, фото и **«Состав блюда (редактируемый текст)»**.
3. Для проверки размера и оформления откройте **[предпросмотр состава](https://tirvia.github.io/GARAGE_Flashcards_NEW/preview.html)**. Выберите блюдо, редактируйте текст и сразу смотрите на результат, без GitHub push. Нажмите «Скопировать состав», вставьте в Source Pages CMS.
4. Нажмите «Сохранить» — GitHub Actions сам пересоберёт каталог. Технические идентификаторы формируются автоматически; редактировать `js/menu-data.js`, `search.html`, `ingredients.html` и `js/flashcards.js` не требуется.
5. Статус **published** публикует карточку, **draft** скрывает черновик, **archived** скрывает архивную карточку. Удаление записи из CMS также автоматически убирает её из меню и обучения. Изображения можно оставить в медиатеке для дальнейшего использования.

### Перенос в другой раздел

Поле «Раздел» — обычный выпадающий список со **всеми разделами**, поэтому его можно свободно менять. Карточка переносится в выбранный раздел, а прежняя ссылка с историческим номером продолжает работать. Повторно загружать фото не нужно. Варианты списка автоматически синхронизируются с коллекцией «Разделы меню» при сборке каталога.

### Разделы, группы, категории состава

Отдельные редакторы «Разделы меню», «Группы меню» и «Категории состава». Новые идентификаторы генерируются при сохранении. Список разделов, групп и категорий состава обновляется в Pages CMS автоматически; прежние названия и тексты стартовой страницы не заменяются.

### Форматирование состава

Теперь шрифт можно уменьшать **в конкретной части карточки**.

- Вкладка **Editor**: выделите фразу и нажмите *Курсив (I)*. Этот фрагмент будет курсивным **и меньшего размера на готовой карточке**.
- Вкладка **Source**: обрамите конкретные слова звёздочками: `*(лук, картофель, яйцо, мука)*`.
- Вложенные ингредиенты отдельным списком размещайте с отступом, их размер будет меньше: `  - Лук репчатый`.
- Обычные ингредиенты оставляйте как `- Масло растительное`. Размер полного списка рассчитывается автоматически, без отдельных полей.
- Списки и пояснения можно сочетать. В [предпросмотре](https://tirvia.github.io/GARAGE_Flashcards_NEW/preview.html) есть кнопки «Ингредиент», «Вложенный», «Мелкий текст» и «По центру» — внешний вид меняется сразу.
- **Pages CMS пока не поддерживает встраивание нашего отдельного рендера карточки непосредственно в форму.** В предпросмотре текст можно готовить без сохранений, затем скопировать в Pages CMS и опубликовать один раз.

Пример для драников:

```markdown
- Драники
  *(лук, картофель, яйцо, мука)*
- Масло растительное
- Свинина грудинка
- Петрушка
- Сметана
```

Шрифт и перенос строк рассчитываются по реальной ширине текста. Фон остаётся белым с оригинальной красной рамкой. Лицевые фото и оформление всех страниц сохраняются.

### Миграция старых составов

- Выполнено автоматическое распознавание **191 изображения состава** и перенос текста в поле `composition`.
- Очистка устранила типичные артефакты распознавания списков.
- **56 составов отмечены как требующие проверки**. До изменения текста они показываются в исходном PNG. После исправления состава в Pages CMS сайт автоматически переключается на текст — снимать отметку вручную не требуется.
- Остальные составы отображаются как текст, но массовое OCR не равно ручной проверке каждого ингредиента. Оригинальные изображения сохранены для сверки и отката.
- Подробный отчёт расположен в `migration-report.json`.

### Что происходит при сохранении

GitHub Actions запускает `scripts/build-menu.cjs`, проверяет ссылки, составы, разделы и уникальность идентификаторов, а затем обновляет `js/menu-data.js`. Запускается автоматический регрессионный тест `scripts/test-menu.cjs`.

Старый репозиторий **Tirvia/GARAGE_Flashcards** не изменялся.
