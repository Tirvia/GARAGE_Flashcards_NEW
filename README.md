# GARAGE Flashcards NEW

Оригинальные страницы, тексты и дизайн GARAGE сохраняются. Каталог редактируется через [Pages CMS](https://app.pagescms.org/) в **Tirvia/GARAGE_Flashcards_NEW**.

## Работа с меню (без редактирования кода)

1. Откройте раздел **«Блюда и напитки»** в Pages CMS.
2. Выберите существующее блюдо или создайте новое. Укажите название, раздел, признаки состава, фото и **«Состав блюда (редактируемый текст)»**.
3. Если требуется, измените поле **«Расположение текста состава»** (auto / center / left) и **«Размер текста состава»** (auto / normal / small).
4. Нажмите «Сохранить» — GitHub Actions сам пересоберёт каталог. Технические идентификаторы формируются автоматически; редактировать `js/menu-data.js`, `search.html`, `ingredients.html` и `js/flashcards.js` не требуется.
5. Статус **published** публикует карточку, **draft** скрывает черновик, **archived** скрывает архивную карточку. Удаление записи из CMS также автоматически убирает её из меню и обучения. Изображения можно оставить в медиатеке для дальнейшего использования.

### Перенос в другой раздел

Достаточно изменить поле «Раздел». Карточка переносится в выбранный раздел, а прежняя ссылка с историческим номером продолжает работать. Повторно загружать фото не нужно.

### Разделы, группы, категории состава

Отдельные редакторы «Разделы меню», «Группы меню» и «Категории состава». Новые идентификаторы генерируются при сохранении; стандартные названия и тексты стартовой страницы не заменяются.

### Форматирование состава

Состав можно набрать прямо в редакторе. Для обычных ингредиентов используйте маркированный список; для вложенных ингредиентов — вложенный список (они отображаются меньшим шрифтом). Для отдельных пояснений — текстовый абзац. Выравнивание и размер карточки регулируются полями в редакторе.

Отображение производится поверх фирменной белой карточки с красной декоративной рамкой. Рамка создаётся автоматически из оригинального изображения, без изменения лицевых фотографий.

### Миграция старых составов

- Выполнено автоматическое распознавание **191 изображения состава** и перенос текста в поле `composition`.
- Очистка устранила типичные артефакты распознавания списков.
- **56 составов отмечены как требующие проверки**. Для них сайт временно показывает исходную PNG-карточку, пока редактор не исправит текст и не снимет отметку «Состав требует проверки после переноса».
- Остальные составы отображаются как текст, но массовое OCR не равно ручной проверке каждого ингредиента. Оригинальные изображения сохранены для сверки и отката.
- Подробный отчёт расположен в `migration-report.json`.

### Что происходит при сохранении

GitHub Actions запускает `scripts/build-menu.cjs`, проверяет ссылки, составы, разделы и уникальность идентификаторов, а затем обновляет `js/menu-data.js`. Запускается автоматический регрессионный тест `scripts/test-menu.cjs`.

Старый репозиторий **Tirvia/GARAGE_Flashcards** не изменялся.
